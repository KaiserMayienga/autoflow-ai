# AutoFlow AI agent service (Phase 2, step 1)

FastAPI + LangGraph service that runs the 7-step workshop pipeline with two
human-in-the-loop pauses: customer clarification and technician review.

## Run
    python -m venv .venv && source .venv/bin/activate
    pip install -r requirements-dev.txt
    cp .env.example .env          # AUTH_DISABLED=1 for local dev
    uvicorn app.main:app --reload
    pytest -q

## API
| Method | Path | Who | Purpose |
|---|---|---|---|
| POST | /requests | customer/technician | Run the graph; may pause for clarification or review |
| POST | /requests/{id}/clarify | owner | Resume with customer answers |
| POST | /requests/{id}/resume | technician | approve / reject / more_info |
| GET | /requests/{id} | owner/technician | Current status, risk, quote, citations |
| GET | /requests/{id}/trace | owner/technician | Step-by-step agent trace |

Statuses: needs_clarification, pending_technician, ready_to_book, approved, rejected, needs_info.
In dev mode (`AUTH_DISABLED=1`) send `X-Dev-Role: customer|technician`.

## Auth
Next.js validates the browser session, then calls this service with a 2-minute HS256 token
(`sub` = user id, `role` = customer|technician) signed with `AGENT_SERVICE_SECRET`.
That secret is separate from the browser session secret. The service refuses to start
without it unless `AUTH_DISABLED=1`, which must never be set on a deployed service.

## Design rules
- Escalation, risk and pricing are deterministic (`rules.py`, `quote.py`). A model may extract fields or draft wording but never prices or de-escalates.
- Money is integer minor units. Keyword matching uses word boundaries.
- Interfaces (`Retriever`, `VehicleRepo`, `LLMProvider`) are the seams for Phase 2.

## Knowledge base and quotes
`app/kb.py` is a port of `lib/kb.ts` and `app/quote.py` of `lib/quote.ts`. `tests/ts_reference.json` holds cases
generated by running the real TypeScript pipeline, and `pytest` checks the Python results match to the cent.
If you edit `lib/kb.ts`, update `app/kb.py` and regenerate that file.
Brake requests are priced inspection-first: the full-scope total plus a low-to-high range.

## Persistence
With `DATABASE_URL` set the service stores each run's checkpoints in Postgres (tables are created automatically on
first start), so a request waiting for a customer or technician survives restarts and redeploys. Request ownership is
part of the stored state. Without it, runs live in memory. `tests/test_persistence.py` restarts the service twice
mid-request against a real database (`TEST_DATABASE_URL=... pytest tests/test_persistence.py`).

## Evaluation
`python -m evals.run_eval` scores the rules against `evals/cases.jsonl` (labels follow workshop policy, not system output).
Headline metric: escalation recall on safety-critical cases, which must stay 100% (`tests/test_eval.py` enforces it).
Add your own cases whenever you find a request the system handles badly.

## Deploying
`render.yaml` at the repo root is a Render Blueprint. Free instances sleep after about 15 minutes idle; the web app falls
back to its built-in pipeline if the service does not answer within 20 seconds.
